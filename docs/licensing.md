A user's right to run or convert a table does not automatically grant redistribution rights. Do not commit, publish, attach to a release, or include table files or extracted assets in GitHub Pages unless the rights holder has explicitly allowed that distribution and the permission is documented.

The public build is intended to let users select their own lawful table file in the browser. Local builds that include extracted assets must stay private unless those assets have a clear license permitting publication.
